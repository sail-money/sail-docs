# Fees & governance

Two short pages:

* [Fee model](fees.md) — the two fee mechanisms, the immutable caps, and the reference `StandardFeePolicy`.
* [Governance](governance.md) — the 48-hour timelock, emergency pause, two-step transfer, and the trusted allowlists.

In one sentence: **fees are bounded by immutable constitutional caps and are zero at launch; all parameter changes flow through a 48-hour timelock; an emergency admin can pause the kernel for at most 72 hours.**
