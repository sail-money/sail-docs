# Getting started

Two ways in, depending on how you work:

* [Quickstart](quickstart.md) — install Sailor and go from nothing to a deployed SMA, a registered mandate, and a dispatched transaction, with real commands.
* [Operate Sailor with a coding agent](coding-agent.md) — the recommended path: scaffold a project, open it in your coding assistant, and let it drive the whole setup. This is Sailor's edge.

Both assume a wallet, an RPC URL for a [supported chain](../guides/multi-chain.md), and Node.js 18+.
